## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize ZBrush projects with client, version and status |
| **Brush Manager** | Track custom brush sets and alpha libraries with category tags |
| **Sculpt Versions** | Log sculpt version milestones with render preview notes |
| **Client Specs** | Document polygon budget and delivery format specs per project |
